Chào mừng đến với câu lạc bộ

Chúng tôi là nhóm sinh viên ngành MIS yêu thích công nghệ. Câu lạc bộ tổ chức các buổi chia sẻ về thiết kế web, cơ sở dữ liệu và phân tích dữ liệu.

Hoạt động nổi bật

Mỗi tháng câu lạc bộ có các hoạt động giúp thành viên thực hành kỹ năng và kết nối với nhau.

  • Workshop thiết kế web với HTML và CSS
  • Buổi chia sẻ về Git và GitHub
  • Mini project theo nhóm

Tin nhanh

  • Tuyển thành viên mới
  • Workshop HTML/CSS tuần tới
  • Nộp bài tập nhóm trước cuối tháng
